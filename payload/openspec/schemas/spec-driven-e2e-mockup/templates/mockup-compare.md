# Mockup Compare

このアーティファクトは specs/ 配下のシナリオのうち画面表示に関わるものを、
モック(モックルート `mockup/` 配下の HTML/CSS/JS)との比較観点に翻訳したものである。
受け入れ基準の原本は specs のシナリオであり、本ファイルで新しい仕様を定義してはならない。

## 作成ルール
- 画面表示に関わる specs/ のシナリオをすべて列挙し、比較するもの・しないもの(比較対象外)を明示する
- 比較観点には VC-NNN 形式の ID を 001 から連番で振る
- 各観点に: 対応シナリオ、モックファイル(モックルート相対)、比較状態、ビューポート、比較範囲、マスク・非表示と理由、許容差分率を記載する
- セレクタ・URL・実装詳細は書かない(実装は apply フェーズの責務)
- ダミーデータの領域は必ずマスク対象にし、理由に「ダミーデータ」と書く。許容差分率を上げてデータの差を吸収しない
- モック専用の要素(説明バーなど)はモック側の非表示対象にする
- 画面表示に関わるシナリオが無い場合は、比較観点一覧を削除して「## 比較対象なし」と理由だけを書く
